# DevStudio Pro — All-in-One Developer Workspace & IDE

DevStudio Pro is an enterprise-grade developer browser workspace created purely with HTML5, CSS3, and modern Vanilla JavaScript (ES6+).

## Features

- **Live Multi-File Editor**: HTML, CSS, and JS editor with real-time synchronized line-numbering and isolated `iframe` sandboxed preview execution.
- **Console Interception**: Captures internal `console.log()` outputs from sandboxed previews and outputs them to an integrated UI terminal.
- **System Architecture Diagrammer**: Custom HTML5 Canvas drag-and-drop system modeling tool with auto-connecting vectors.
- **Algorithm Visualizer**: Asynchronous step-by-step array visualization engine for sorting algorithms (Bubble Sort & Insertion Sort).
- **Code Analytics**: Token scanner computing Lines of Code (LOC), function counts, and cyclomatic complexity estimates.
- **State Exporting**: Complete project workspace export/import via JSON payloads and `localStorage` persistence.

## Tech Stack

- **HTML5**: Canvas API, Sandbox Context, Semantic Structure
- **CSS3**: Custom CSS Tokens/Variables, Flexbox, Grid
- **JavaScript**: ES6+ Class Modules, Async/Await Event Loops, Canvas Context Rendering

## How to Run

1. Clone or download the repository.
2. Open `index.html` in any standard modern web browser.
3. No build tools, Node.js installation, or library dependencies are required!
